# Also-Lets-Try

Let’s Try web flash cards, classroom activities, and shared teaching tools.

## Repository plan

```text
Also-Lets-Try/
├── units/       Current Let’s Try unit/activity pages
├── js/          Shared JavaScript and vocabulary data
├── css/         Shared styles
├── images/      Project-owned/shared image assets
└── archive/     Preserved older development snapshots
```
