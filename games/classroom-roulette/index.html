How should it spin?

Click the centre button to spin, or grab the outer wheel and flick it. The pointer slows it down.

How long should a click spin?

12s

Approximate time only. Flicking harder can change how long it spins.

Counts are always saved. A physically spinning wheel can still land on a number already picked; that result is not counted until you flick somewhere available.

Save your classes

Classes and numbers are saved in this browser. If you clear browser data or change computer, they may disappear, so keep a backup file.

You can also import backups from earlier Classroom Roulette versions. Loading a backup replaces current saved classes after confirmation.
